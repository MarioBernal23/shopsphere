# ShopSphere

ShopSphere es un proyecto personal de un e-commerce desarrollado para aprender el desarrollo de aplicaciones web con Java y Spring Boot.

## Tecnologías

- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven

## Funcionalidades actuales

- Gestión de categorías (CRUD)
- Gestión de productos (CRUD)
- Gestión de excepciones

## Próximas funcionalidades

- Usuarios
- Autenticación con JWT
- Carrito de compra
- Pedidos
- Sistema de recomendaciones
- Frontend con React

## Cómo ejecutar el proyecto

1. Clonar el repositorio.
2. Crear una base de datos PostgreSQL.
3. Configurar `application.properties`.
4. Ejecutar la aplicación desde IntelliJ o con Maven.
